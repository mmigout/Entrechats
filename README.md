# Entrechats 💃

Projet de gestion d'une association de danse.

## Fonctionnalités prévues

- Gestion des adhérents (nom, prénom, adresse, email, téléphone)
- Authentification sécurisée via AWS Cognito
- Frontend React.js
- Backend serverless AWS (Lambda + API Gateway + DynamoDB)
